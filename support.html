Nik5W1H Private Support

Support information for Nik5W1H Private

Nik5W1H Private is a personal memory and information management application designed to help users remember and organize information using the familiar:

  • What
  • Where
  • When
  • Who
  • Why
  • How

Items can also contain notes, photographs, scanned documents, OCR text, locations and other attachments.

Storage Options

Nik5W1H Private supports three storage options.

Local Storage

Information is stored locally on the device.

iCloud Storage

Information is stored and synchronized using Apple's iCloud and CloudKit services.

The device must be signed in to an Apple Account with iCloud available for iCloud synchronization to operate.

Private Backend Storage

Nik5W1H Private includes an optional capability to communicate with a compatible private backend service.

Important: Nik5W1H Private does not include a public backend hosting service.

Users who choose the Private Backend option are responsible for providing and operating their own compatible backend infrastructure.

This includes responsibility for:

  • backend installation and configuration;
  • server and network operation;
  • access control and authentication;
  • server security;
  • software maintenance;
  • data backup and recovery; and
  • data retention and permanent deletion.

The developer does not provide general backend hosting, administration, maintenance, security management, recovery services or technical support for independently operated backend systems.

Permissions

Depending on the features you use, Nik5W1H Private may request permission to access device services such as:

  • Camera
  • Photo Library
  • Microphone
  • Speech Recognition
  • Location
  • Files and Documents

These permissions are used only when required by the corresponding application features.

Permissions can be reviewed or changed using the privacy settings provided by the operating system.

iCloud Synchronization

When iCloud Storage is selected, synchronization is performed using Apple's iCloud and CloudKit infrastructure.

Synchronization may not always occur immediately. Timing can depend on network connectivity, iCloud availability, device status and Apple's synchronization services.

If information has not yet appeared on another device, ensure that both devices are using the appropriate Apple Account, have iCloud available and have an active network connection.

Attachments

Nik5W1H Private can store attachments including photographs, scanned documents, files, OCR information and saved locations.

Availability and synchronization of attachments depend on the selected storage method.

When using a private backend, attachment storage and backup depend on the configuration and operation of that backend.

Backup

Users are encouraged to maintain appropriate backups of important information.

Backup behaviour depends on the selected storage method and the backup facilities available on the device, through iCloud, or through a user-operated private backend.

Users operating a private backend are responsible for establishing and maintaining their own backup and recovery procedures.

Deleting Information

Individual Nik5W1H items can be deleted using the application's available deletion functions.

For Local Storage and iCloud Storage, deletion and synchronization behaviour also depends on the relevant device and Apple services.

When using Private Backend Storage, deletion from independently maintained backups may require action by the backend operator.

Private Backend Compatibility

The Private Backend feature requires a backend service that is compatible with the communication and data requirements of Nik5W1H Private.

The application does not automatically install, configure, administer or secure a backend server.

Access to Nik5W1H Private does not guarantee access to a private backend. Backend access must be separately configured and authorized by the operator of that backend.

Troubleshooting

If Nik5W1H Private is not behaving as expected, try the following:

  • Confirm that the appropriate storage option is selected.
  • Check the device's network connection.
  • Check that required application permissions have been granted.
  • For iCloud Storage, confirm that iCloud is available on the device.
  • For Private Backend Storage, confirm that the configured backend is running and reachable from the device.
  • Close and reopen Nik5W1H Private if necessary.

Privacy

Information about how Nik5W1H Private handles user information is provided in the Nik5W1H Private Privacy Policy.

Users operating a private backend are responsible for the privacy and security practices applicable to their own backend infrastructure.
